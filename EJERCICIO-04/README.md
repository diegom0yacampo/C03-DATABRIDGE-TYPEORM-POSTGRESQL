# Ejercicio 04 · Food Spots

Formulario en React Native que envía un restaurante nuevo con POST /restaurantes.
El Controller recibe el Body con @Body() y un DTO, y el Service lo guarda con create() y save().
Se ha añadido precioMedio a la Entity, al DTO, al formulario y a la tarjeta del restaurante guardado.
Los datos quedan en la tabla restaurantes de databridge_e04.
