# Ejercicio 10 · Wander

CRUD de destinos de viaje con NestJS, TypeORM y PostgreSQL (databridge_e10).
El backend tiene Entity, DTOs de creación y actualización, Service con Repository y Controller con GET, POST, PATCH y DELETE.
La app lista los destinos, permite crear uno nuevo con un formulario y eliminarlo.
Tras cada cambio se vuelve a pedir la lista a la API para mantener la pantalla sincronizada.
